# Talent Dashboard V2

## Product intent

The Talent home dashboard is a focused next-action surface, not a duplicate of every destination in the Talent workspace.

### Rules

- Show exactly one primary workflow action at the top: complete profile, submit for review, wait for review, fix requested changes, or browse opportunities after approval.
- Keep approval readiness, applications, saved opportunities, and unread messages as compact metrics.
- Show missing approval requirements only while the profile is incomplete.
- Show recent application progress only when applications exist, including the opportunity title and current stage.
- Keep Portfolio and Profile Strength as optional growth actions.
- Do not duplicate profile-photo management, full notifications, full messages, or large empty states on the home dashboard.
- On desktop the Talent navigation rail should read as a persistent right-side workspace rail rather than a floating card; mobile navigation remains unchanged.

## Application stages shown on Home

- pending → Submitted / New
- reviewing → In review
- shortlisted → Shortlisted
- accepted → Accepted
- rejected → Not selected

The full Applications page remains the source of truth for all application history and details.
