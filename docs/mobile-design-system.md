# MLAMH Mobile Design System

## 1. الهدف

هذه الوثيقة هي المرجع الرسمي لتصميم واجهات الجوال في مشروع MLAMH.

جميع تطويرات الجوال يجب أن:

- تعمل على الشاشات الصغيرة أولًا.
- تحافظ على تصميم Desktop الحالي.
- لا تغيّر Architecture أو Routing أو Supabase أو Authentication.
- تستخدم مكونات مشتركة بدل تكرار التصميم داخل الصفحات.
- تحافظ على هوية MLAMH الهادئة والفاخرة.
- تستلهم بساطة التطبيقات الحديثة دون نسخ تصميم أي منصة.

---

## 2. نطاق التطبيق

تُطبق هذه القواعد على:

- Mobile Header
- Bottom Navigation
- Mobile Drawer
- البحث
- بطاقات المواهب
- بطاقات الفرص
- صفحات التفاصيل
- لوحات التحكم
- الرسائل
- الإشعارات
- النوافذ السفلية
- النماذج والأزرار
