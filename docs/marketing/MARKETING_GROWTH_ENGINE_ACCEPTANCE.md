# MLAMH Growth Engine Acceptance Criteria

A growth-engine change is complete only when:
- it reuses an existing MLAMH system where one already exists;
- the intended audience and market are explicit;
- the action has a measurable event or outcome;
- approval requirements are defined;
- protected talent data remains protected;
- no duplicate email, social, analytics, CRM, or AI orchestration path is introduced;
- related changes are batched before deployment where practical;
- validation is recorded before a task is marked DONE.

## Funnel metrics
Talent: visit -> signup -> profile completion -> submission -> approval -> opportunity view -> application.
Publisher: lead -> outreach -> reply -> brief -> opportunity -> reviewed applications -> selection -> connection.

## Quality metrics
- qualified acquisition, not raw traffic alone;
- positive reply and brief conversion, not send volume alone;
- qualified applications, not application count alone;
- marketplace liquidity and time-to-match;
- referral users who activate;
- experiment lift with sufficient evidence.
