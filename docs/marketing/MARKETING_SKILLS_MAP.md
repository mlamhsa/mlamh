# MLAMH Marketing Skills Map

Status: APPROVED BASELINE
Purpose: Map external Marketing Skills knowledge into existing MLAMH systems without duplicating product capabilities.

## Classification
- USE: active priority; integrate knowledge into existing MLAMH workflows.
- ADAPT: MLAMH already has part of the capability; import only useful frameworks/checklists.
- LATER: valuable after data, monetization, mobile-store, or paid-growth readiness.
- SKIP: redundant as an independent subsystem.

## SKIP as independent subsystem
### marketing-council
MLAMH already has AI Team, Tasks, Approvals, Control and governance. Importing a separate AI council would duplicate authority and create conflicting orchestration.

## Integration rules
1. Never install a skill merely because it exists.
2. Prefer copying/adapting frameworks and checklists into MLAMH Playbooks where they materially improve execution.
3. Preserve MLAMH governance, approvals and production-write restrictions.
4. Do not introduce a second outreach, email, analytics, experiment, CRM, content or AI-team system.
5. Every integrated skill must have a measurable business or marketplace outcome.
6. Skills that affect external communication remain subordinate to channel-specific approval policy.
7. Re-evaluate LATER skills only when the prerequisite business stage exists.
